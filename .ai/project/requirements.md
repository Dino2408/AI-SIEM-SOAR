# Project Requirements

Build one finished SIEM/SOAR product using four fixed AI development roles.

- Architect: architecture, planning and task decomposition.
- Developer: source implementation.
- DevOps & Tester: Docker, datasets and deterministic testing.
- SOC Manager & Validator: evidence-based evaluation.

The Orchestrator is infrastructure, not a fifth agent. Feedback loops are bounded and are for normal defect correction, not continuous self-evolution.
